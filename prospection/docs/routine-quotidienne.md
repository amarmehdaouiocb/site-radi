# Routine Quotidienne de Prospection

## Vue d'ensemble

**Temps total** : ~1h/jour
**Objectif** : Générer un flux constant de leads et maintenir le pipeline

---

## Routine du Matin (30 min)

### 1. Check CRM (10 min)

- [ ] Ouvrir le Google Sheets CRM
- [ ] Vérifier les emails d'alerte (relances du jour)
- [ ] Identifier les leads à contacter aujourd'hui
- [ ] Mettre à jour les statuts des leads contactés hier

### 2. Veille Facebook (15 min)

- [ ] Ouvrir les 5 groupes Facebook prioritaires
- [ ] Rechercher les mots-clés : "artisan", "travaux", "recommandation"
- [ ] Répondre aux posts pertinents (max 5 réponses)
- [ ] Noter les leads dans le CRM avec source "Facebook"

### 3. Check emails (5 min)

- [ ] Vérifier les réponses aux emails B2B envoyés
- [ ] Répondre aux demandes de contact
- [ ] Mettre à jour le CRM avec les réponses

---

## Routine du Midi (15 min)

### Envoi Cold Emails B2B

- [ ] Sélectionner 10-15 leads B2B en statut "Nouveau"
- [ ] Personnaliser et envoyer les emails (template syndic ou agent immo)
- [ ] Mettre à jour le statut en "Email 1" dans le CRM
- [ ] Noter la date de contact et la date de relance (J+3)

---

## Routine du Soir (15 min)

### Suivi et préparation

- [ ] Recheck Facebook (nouveaux posts de la journée)
- [ ] Répondre aux messages privés
- [ ] Préparer les relances pour demain
- [ ] Mettre à jour l'onglet Activité du CRM

---

## Routine Hebdomadaire (1-2h)

### Lundi : Planification

- [ ] Revoir les objectifs de la semaine
- [ ] Vérifier le stock de leads (assez pour la semaine ?)
- [ ] Planifier les envois de courriers

### Mercredi : Import de leads

- [ ] Vérifier les nouvelles données Sit@del (si disponibles)
- [ ] Lancer un import DVF (1 département)
- [ ] Qualifier les nouveaux leads

### Vendredi : Analyse

- [ ] Remplir le rapport d'activité hebdo
- [ ] Calculer les taux de conversion
- [ ] Identifier ce qui fonctionne / ne fonctionne pas
- [ ] Ajuster la stratégie si nécessaire

---

## Routine Mensuelle (2-3h)

### Début de mois

- [ ] Télécharger les nouvelles données Sit@del
- [ ] Import complet tous départements IDF
- [ ] Générer et imprimer les courriers
- [ ] Poster les courriers

### Milieu de mois

- [ ] Bilan des courriers envoyés (retours ?)
- [ ] Ajuster les templates si besoin
- [ ] Enrichir la base B2B (nouveaux syndics/agents)

### Fin de mois

- [ ] Rapport mensuel complet
- [ ] Nettoyage du CRM (archiver les leads perdus)
- [ ] Objectifs pour le mois suivant

---

## Check-list Envoi Courriers

### Préparation (30 min)

1. [ ] Sélectionner 20-30 leads qualifiés
2. [ ] Générer les PDFs via le CRM
3. [ ] Télécharger tous les PDFs

### Impression

- [ ] Imprimer en recto seul
- [ ] Qualité : Standard (pas brouillon)
- [ ] Papier : 80g minimum

### Mise sous pli

- [ ] Enveloppes C5 (162x229mm) pour format A4 plié
- [ ] Adresse destinataire en bas à droite
- [ ] Timbre vert (lettre verte) = 1,29€

### Envoi

- [ ] Poster à La Poste ou boîte aux lettres
- [ ] Mettre à jour le CRM : statut "Contacté"
- [ ] Noter la date d'envoi

| Emails B2B envoyés | 10-15 |
| Leads CRM mis à jour | 10+ |

---

## Conseils pour rester efficace

### Automatiser ce qui peut l'être

- Configurer les alertes Google
- Utiliser les templates d'emails préparés
- Laisser le script CRM générer les PDFs

### Bloquer du temps dédié

- Pas de multitâche pendant la prospection
- Désactiver les notifications
- Timer de 15 min par bloc

### Mesurer pour s'améliorer

- Noter ce qui génère des réponses
- Tester différents objets d'email
- Analyser les jours/heures les plus efficaces

### Ne pas se décourager

- La prospection est un jeu de volume
- 2-5% de taux de réponse est normal
- Un seul chantier signé peut valoir des dizaines de courriers

---

## En cas de rush

Si pas le temps pour la routine complète, prioriser :

1. **Minimum 5 min** : Check emails + réponses urgentes
2. **Minimum 15 min** : + Veille Facebook rapide
3. **Minimum 30 min** : + Envoi 5 emails B2B

Rattraper le reste le lendemain.
